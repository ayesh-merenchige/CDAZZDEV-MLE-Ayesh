## Task 2A — Use Case & Dataset (30 pts)

### Problem Statement
- **Input:** A raw contract clause (free text, 2-6 sentences, any industry)
- **Output:** JSON object `{clause_type, risk_level, key_obligations, summary}`
- **Correct:** Parseable JSON, all fields present, `clause_type` in fixed enum, `risk_level` in {low, medium, high}, content reflects the clause
- **Incorrect:** Malformed JSON, missing fields, wrong enum values, hallucinated clause type, contradictory summary

### Dataset
- **235 examples** generated by teacher model across 20 seed topics × 10 industries
- Deduplicated (exact + fuzzy)
- Diversity metrics: prompt-length histograms, topic/clause_type/risk_level frequencies
- 18 unique topics, 20 unique clause_types, 10 industries

### Format
- JSONL with Qwen2.5 chat template (system/user/assistant turns)
- 80/10/10 split: train 188, val 23, test 24

## Task 2B — Fine-Tuning Execution (40 pts)

### QLoRA Configuration

```python
BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16,
    bnb_4bit_use_double_quant=True
)
```

### Hyperparameter Justification

| Hyperparameter | Value | Justification |
|---|---|---|
| LoRA rank `r` | 16 | Small package (structured JSON output); balances expressivity vs. small trainable footprint |
| LoRA alpha | 32 | alpha/r = 2 is standard scaling |
| Target modules | q/k/v/o/gate/up/down | Adapts attention and MLP layers |
| Learning rate | 2e-4 | Conservative LoRA LR; 1e-3 diverges, 5e-5 underfits |
| LR scheduler | cosine | Smooth decay to ~0; warmup_steps=6 |
| Epochs | 4 | Enough to see val-loss flatten; >6 overfits 172 train rows |
| Batch size | 4 | T4 16GB constraint |
| Grad accumulation | 4 | Effective batch 16 |
| Max seq length | 1024 | 95th-pct example ≈ 700 tokens |
| Grad checkpointing | on | Memory headroom at bs=4/len=1024 |
| Optimizer | paged_adamw_8bit | Matches QLoRA memory profile |
| Weight decay | 0.0 | LoRA already regularizes |

### Training Results

| Epoch | Training Loss | Validation Loss |
|---|---|---|
| 0 | 4.980 | 0.384 |
| 1 | 0.280 | 0.191 |
| 2 | 0.171 | 0.177 |
| 3 | 0.156 | 0.175 |

**Validation loss decreases across all epochs.**
